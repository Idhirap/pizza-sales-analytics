# 🍕 Pizza Sales Analytics

An end-to-end data analytics portfolio project analyzing pizza sales data using **SQL Server and Microsoft Excel**.

The project covers data import, SQL-based analysis, data cleaning, data processing, Excel-based analysis, and an interactive dashboard to identify sales trends and top-performing products.

---

## 📌 Project Overview

This project analyzes pizza sales data to understand:

- Overall sales performance
- Daily and hourly order trends
- Sales contribution by pizza category
- Sales contribution by pizza size
- Best and worst-selling pizzas
- Customer ordering patterns

The analysis was performed using **SQL Server for data analysis** and **Microsoft Excel for data processing, visualization, and dashboard creation**.

---

## 💡 Key Insights          

- Classic category generated the highest share of sales at 26.91%, with 14,888 pizzas sold.
- Large-size pizzas dominated sales, contributing 45.89% of total pizza-size sales.
- Friday was the busiest day with 3,538 orders, followed by Saturday.
- Order volume peaked at 12 PM with 2,520 orders, with another strong period between 5 PM and 8 PM.
- Large and Medium pizzas together accounted for 76.38% of pizza-size sales.
